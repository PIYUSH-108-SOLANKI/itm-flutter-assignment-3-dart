# Library Management System


## Run

```bash
dart library_management.dart
```

## description
This is a simple library management system implemented in Dart. It allows users to manage books in a library, including adding new books, viewing available books, borrowing and returning books, and searching for specific books. The system also provides library statistics, such as the total number of books and the number of books currently borrowed.

- Add, view, borrow, return, and search books
- View library statistics
- Uses classes, private fields, abstraction, inheritance, and overriding
